# Plateforme de QCM en Ligne

**Plateforme de QCM en Ligne** est un outil interactif permettant de creer, gerer et passer des questionnaires a choix multiples de maniere efficace.

## Fonctionnalites Principales
- Creation de QCM personnalises (questions, options, corrections)
- - Prise de test en temps reel par les utilisateurs
  - - Correction automatique et affichage des scores
    - - Gestion des categories et des niveaux de difficulte
     
      - ## Stack Technique
      - - Backend : PHP
        - - Frontend : HTML5, CSS3, JavaScript
          - - Base de donnees : MySQL
           
            - ## Installation
            - 1. Clonez le depot
              2. 2. Importez le fichier SQL present dans le dossier sql/
                 3. 3. Configurez la connexion a la base de donnees dans includes/db.php
